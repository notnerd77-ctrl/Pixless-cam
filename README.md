# PIXLESS-CAM

**Photography, reimagined through pixels.**

Pixless-Cam is an experimental digital camera project that transforms ordinary photographs into distinctive pixel-based visual compositions.

The project explores the intersection of photography, digital art, retro aesthetics and image processing.

## About

Pixless isn't simply about reducing image resolution. It's about reinterpreting photographs through pixels while retaining the visual identity and composition of the original scene.


## Features

- Transform photographs into pixel-based artwork.
- Explore retro-inspired visual aesthetics.
- Experiment with colour and pixel representation.
- Reinterpret everyday photography through a different visual language.
